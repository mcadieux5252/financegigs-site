# FinanceGigs.ai marketing site

Static site hosted on Netlify (project `financegigs`), linked to this repo since 2026-11-03: a merge to `main` publishes it. Pages: `index.html`, `employers.html`, `privacy.html`, `terms.html`, `thanks.html` (left from the early access form, which was removed on 2026-11-03 once sign-ups opened at app.financegigs.ai/join).

Since November 2026 the pages are ported from the SupplyChainGigs site (github.com/mcadieux5252/supplychaingigs-site) with finance copy and the FinanceGigs red: free Sync and Sync+ pricing, join and sign-in links to app.financegigs.ai, and the employer page. When the SupplyChainGigs pages change, port the change here. `build.py` is the older generator and no longer matches these pages.

`index.html` follows the ProcurementGigs.AI home page layout (procurement-gigs.com) with finance copy and the FinanceGigs red, and is edited directly. `privacy.html`, `terms.html` and `thanks.html` are still generated by `build.py`, which builds both InfoTechGigs and FinanceGigs from one template; edit the `BRANDS` entry or the template, run `python3 build.py`, and copy those three files for this brand into the repo root.

The SMS consent wording on the app's join page (app.financegigs.ai/join), privacy policy and terms matches the Twilio toll-free verification. Keep it unchanged unless the verification is updated too.
